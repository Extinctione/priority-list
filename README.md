Priority List

Priority List is a simple, interactive web app to help you rank and prioritize your tasks. Enter your tasks, compare them pairwise, and see your priority order at the end.

Features

Enter tasks (one per line) and compare them two at a time.

Interactive priority ranking based on your choices.

Smooth fade and slide transitions between input, comparison, and results.

Cute pink-themed buttons and semi-transparent cards.

Fully self-contained HTML file — no setup required.

Restart button to try different task sets quickly.

Usage

Open priority-list.html in any modern browser.

Enter your tasks in the textarea (one per line).

(you can mainly connect it to codepen and use it on notion or any note app you prefer)

Click Start.

For each pair of tasks, select the one that is more important.

View your priority ranking at the end.
